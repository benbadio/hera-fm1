INSTALL MORPHEUS

How to flash the M-VAVE FM-1 groovebox hardware

Emulator Manual Source

Method 1: Web MIDI Browser Install

The simplest and safest way to flash MORPHEUS onto your M-VAVE FM-1 without installing command-line tools:

  1. Connect your M-VAVE FM-1 to your computer using the USB-C cable and turn it on.
  2. Open Google Chrome, Opera, or Microsoft Edge (browsers with native Web MIDI support).
  3. Select MORPHEUS (Package ID: FM-1_945).
  4. Click Install Firmware and confirm the Web MIDI permission. The device will be safely updated in under 30 seconds and reboot into MORPHEUS!

Method 2: Command Line USB Install (Python)

If you downloaded the morpheus.fwsc package directly from GitHub Releases or built it locally: 

# 1. Install required python libraries
pip3 install mido python-rtmidi

# 2. Flash the firmware package over USB
python3 tools/fm1_install.py build/morpheus.fwsc

# 3. Check installed firmware on the FM-1
python3 tools/fm1_install.py --info

USB Rescue Mode (Safe Recovery)

If an install is ever interrupted or you wish to revert to stock firmware:

Hold the OCT- button on the FM-1 while turning on the power switch. The screen will remain dark and the device will boot into the hardware bootloader rescue mode. You can immediately reinstall any firmware or stock build via USB or Web MIDI.
